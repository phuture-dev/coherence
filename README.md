## Introduction

**Coherence** is a modern PHP utility library that brings consistency and elegance to your codebase with well-thought, fluent, chainable helpers.

This repository contains the official **Phuture Coherence** package. To learn more about **Phuture Coherence** and how to use this package, please consult the [official documentation](https://docs.phuture.dev/).

## Features

- 🎯 **Arrays** - Advanced manipulation and data processing for arrays
- 📝 **Strings** - Powerful string utilities
- 🔐 **Hash** - Secure hashing, passwords, HMAC, and more
- 🔗 **URL** - URL parsing, building, and manipulation
- 🌐 **HTML** - HTML escaping, sanitization, and building
- 📞 **Callable** - Function, methods and classes composition and utilities

## Installation

```bash
composer require phuture/coherence
```
